# Projects

Each subfolder here is one project you build during the course — a full thing you're
making from start to finish (an app, a prototype, a tool).

To start a new project:
1. Create a folder: `projects/<project-name>/`
2. Add a short `README.md` inside it describing what it is and why you're building it
3. Ask Claude Code to help you scaffold and build it

Example: `projects/fitness-tracker/`
