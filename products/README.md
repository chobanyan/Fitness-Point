# Products

This folder is for work that's meant to go further than a course exercise — a
product concept you're taking seriously, with things like a PRD, target users, and
a real roadmap, not just a one-off build.

To start a new product:
1. Create a folder: `products/<product-name>/`
2. Add a `PRD.md` (problem, target users, scope, success metrics)
3. Build it out with Claude Code's help as the scope firms up

Example: `products/aca/`
