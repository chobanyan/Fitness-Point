# Skills

This folder is for smaller, focused exercises where you're practicing one specific
skill (e.g. writing a PRD, working with Claude Code's slash commands, a specific
coding or workflow technique) rather than building a full project.

To add a new skill exercise:
1. Create a folder: `skills/<skill-name>/`
2. Add a short `README.md` describing what you're practicing and what "done" looks like

Example: `skills/writing-prds/`
